Blame you can check by running the team again.

When a team of AI agents fails, this project measures each agent's share of the failure by replaying the run with that agent swapped for a declared reference. The result is a number with an error bar, not a judge's opinion.

01 · The problemLogs cannot say who caused a failure.

Regulators now ask for records of what AI systems did (EU AI Act, Article 12). For a team of agents, a record shows who acted, not who was responsible. Two teams can leave identical logs and still differ in which agent the outcome depended on (Theorem T5).

Current attribution work labels failures with an LLM judge or with the earliest step that, once fixed, saves the run. Reviewers of those papers kept asking the same question: is the label true? This project answers by measurement. Reset the simulator, replace the agent's actions with a declared reference, execute the branch, and compare.

02 · The methodFour steps from a failed run to a number with an error bar.

01

Intervene

Agents outside a coalition take their declared reference for a window. The branch is executed, never imagined.

02

Share fairly

Shapley values split the outcome over agents. When two faults are both needed, each gets half.

03

Cancel the noise

Every coalition reuses the same random numbers, so shared randomness drops out of the differences.

04

Amortise and audit

A permutation-equivariant critic answers instantly; its least certain decisions go to a Monte Carlo audit.

04 · TestbedThe earliest error is not always the cause.

A replayable three-role team (planner, solver, verifier) on checkable arithmetic tasks, 4,000 episodes per setting. The agents are scripted with error rates, not language models yet: this tests the measurement and the protocol.

In a uniformly weaker team, 12.4% of failures have no single decisive error, so the convention used by Who&When, AgenTracer and Aegis returns nothing, while measured responsibility still assigns blame. 39% of those failures have blame shared by two or more agents.

Repair: rerun with the blamed agent replaced

Weaker team, 1,549 failures, 95% bootstrap intervals

Measured blame repairs as often as the earliest-error rule here and also covers the failures that rule cannot label. Real LLM agents plug into the same harness next.
